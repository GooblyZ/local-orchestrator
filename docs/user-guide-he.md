# מדריך שימוש קצר — Codex + Claude

Codex מתכנן, נותן הוראות ובודק. Claude Code כותב קוד ומריץ בדיקות. הכל קורה בדפדפן, בלי להקליד פקודות.

## הפעלה

1. לחץ פעמיים על `start.cmd` בתיקייה `local-ai-orchestrator`.
2. ייפתח חלון שחור קטן — הוא מפעיל את השרת המקומי. אפשר למזער אותו, אבל לא לסגור אותו בזמן שמשימה רצה.
3. האפליקציה נפתחת בדפדפן. אם היא כבר פועלת, לחיצה נוספת על `start.cmd` רק פותחת אותה שוב.

## משימה חדשה

1. כתוב בתיבה הגדולה ("מה תרצה שהם יעשו?") ולחץ **התחל משימה**.
2. המערכת בודקת ש-Codex ו-Claude מחוברים, בלי לפנות למודל, ומציגה סיכום:
   - המשימה ותיקיית העבודה — ברירת המחדל היא תיקייה חדשה ונקייה.
   - מה מותר בלי לשאול, ומה חסום תמיד.
   - המודלים והגבולות.
   - הסיכון: הקוד ירוץ במחשב שלך בהרשאות שלך.
3. סמן **"אני מאשר הרצה מקומית"** ולחץ **אשר והתחל**. המשימה לא תתחיל בלי האישור הזה, וגם אם תכתוב "כן" בתוך המשימה, זה לא נחשב אישור.
4. השיחה בין Codex ל-Claude מוצגת בזמן אמת: מי עובד, סבבים, תקצירים בעברית, ותוצאות הבדיקות שהמערכת הריצה בעצמה.
5. בסוף מופיעים כרטיס התוצאה ורשימת הקבצים. אפשר לצפות בכל קובץ או לפתוח את התיקייה.

**משימות ארוכות:** אפשר להדביק עד 200,000 תווים (מונה מתחת לתיבה). המשימה נמסרת לסוכנים במלואה, בלי קיצור. משימה ארוכה נשמרת גם בקובץ `.orchestrator/TASK.md` בתיקיית העבודה, ו-Claude חוזר אליו בסבבים הבאים במקום לקבל את כל הטקסט שוב.

## הגדרות סוכנים (לא חובה)

בדף הבית יש קטע "הגדרות סוכנים":
- מודל Codex ומאמץ החשיבה שלו.
- מודל Claude ומאמץ החשיבה שלו.
- מספר סבבי התיקון.

מוצגות רק אפשרויות שהגרסאות המותקנות מציעות דרך המנויים שלך. אין API בתשלום ואין מצב מהיר. הבחירה נשמרת לפעם הבאה, והמודלים בשימוש מוצגים בצד השיחה.

## עד להשגת המטרה, או מגבלת סבבים

- **עבודה עד להשגת המטרה** (ברירת המחדל): הסוכנים ממשיכים עד שהמטרה מאומתת — כלומר הבדיקות שהמערכת מריצה עוברות ו-Codex מאשר.
  - יש גבולות שאתה קובע: זמן, מספר קריאות, ונקודת בדיקה כל כמה סבבים.
  - כשמגיעים לגבול, המשימה נעצרת ושום דבר לא אובד. מופיעים כפתורים כמו **הגדל תקציב והמשך**.
  - רק אתה יכול להגדיל גבול. הסוכנים לא יכולים.
  - אם הסוכנים נתקעים (אותה טעות שוב ושוב, או אין התקדמות), המשימה נעצרת ושואלת אותך.
  - אין מגבלת זמן לקריאה בודדת ואין מגבלת סבבים. סוכן יכול לחקור שעה בקריאה אחת.
  - כשנגמר תקציב הזמן באמצע עבודה, המשימה מושהית. הקבצים והשיחה של Claude נשמרים, ואחרי הגדלת התקציב היא ממשיכה מאותה נקודה.
  - פעילות Claude (חיפושים, קריאת אתרים, קבצים) מוצגת בזמן אמת.
  - אם אין פעילות נראית כמה דקות, תופיע הודעה. המערכת לא עוצרת לבד: אתה מחליט אם לחכות או לעצור.
- **עבודה עם מגבלת סבבים**: למשימות קצרות. אחרי מספר הסבבים שבחרת, העבודה מסתיימת.
- **בצד השיחה** ("מטרה והתקדמות") רואים:
  - הקריטריונים, עם סימון מצב לפי Codex.
  - כמה סבבים, זמן וקריאות נוצלו.
  - האסטרטגיה הנוכחית.
  - סיבת העצירה.

## אינטרנט

Codex ו-Claude יכולים לחפש ולקרוא מידע ציבורי ברשת, כולל נתוני שוק ציבוריים, בלי שתצטרך לספק את הנתונים בעצמך.
- כל מקור נרשם בשיחה, עם כתובת וזמן האחזור.
- קבצי סיסמאות ומפתחות חסומים לקריאה.
- אין הרשמה, כניסה לחשבונות, רכישות או מסחר.

## משימת מחקר

בהגדרות בחר **"מחקר"**:
- Claude כותב דוח (`RESEARCH_REPORT.md`) במבנה ובשפה שהמשימה שלך מגדירה. קריטריוני ההצלחה נגזרים מהמשימה עצמה.
- בדוח חייבים להיות מקורות עם תאריך, ושורת `Verdict:` בסוף, לפי ההחלטות שהמשימה מגדירה (למשל GO / PIVOT / NO-GO / INCONCLUSIVE).
- המערכת בודקת רק את המבנה הזה. **היא לא בודקת שהמסקנה נכונה.** Codex בודק את התוכן מול המשימה.
- רק במחקר על אסטרטגיית מסחר: טענה ל"יתרון רווחי" בלי בדיקה מחוץ למדגם ובלי עלויות נדחית.
- אם אין מספיק ראיות, התוצאה תהיה **"לא חד-משמעי" (INCONCLUSIVE)**, ולא "הצלחה".
- לעולם לא מתבצעים מסחר, תשלום או כניסה לחשבונות.

## כש-Claude מבקש הרשאה

- Claude יכול לקרוא ולכתוב קבצים בתיקיית העבודה ולהריץ בדיקות (`python -m unittest`, `python -m pytest`) בלי לשאול.
- כל פעולה אחרת נחסמת. בשיחה יופיעו הפעולה המדויקת, התיקייה והסיכון, עם הכפתורים **אשר פעולה זו** ו**דחה**.
- אישור חל רק על המשימה הזו ועל הפעולה המדויקת הזו. אותה שיחה עם Claude ממשיכה.
- **לעולם לא יאושרו:** גישה כללית ל-shell, מחיקות, `git push`, והורדות או התקנות.

## השהיה וביטול

- **השהה:** הפעולה תיעצר אחרי הצעד הנוכחי, ואפשר להמשיך אחר כך בלחיצה על **המשך**.
- **בטל משימה:** עוצר מיד, גם קריאה שרצה כרגע.
- **אם החלון השחור נסגר באמצע:** בשיחה יופיע "הריצה נקטעה", ואפשר ללחוץ **המשך**.
